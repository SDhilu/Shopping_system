# Volt Store

A modern fashion e-commerce storefront built with React, featuring product discovery, interactive shopping cart functionality, and a bold, responsive interface.

## Overview

Volt Store is a frontend project exploring e-commerce user experience, interactive UI development, and client-side state management through a fashion retail storefront.

## Key Features

- **Product Discovery** — browse products by category and search by name.
- **Price Sorting** — sort products from low to high or high to low.
- **Shopping Cart** — add items, update quantities, remove products, and calculate subtotals.
- **Wishlist** — save products during the current session.
- **LocalStorage Persistence** — retain cart contents across browser sessions.
- **Interactive Interface** — responsive navigation, product cards, and a slide-out shopping cart.

## Technology Stack

- **React 19** — component-based UI development
- **Vite** — development and build tooling
- **JavaScript** — application logic and state management
- **CSS** — styling and layout
- **Lucide React** — interface icons
- **LocalStorage** — client-side cart persistence

## Getting Started

Clone the repository:

```bash
git clone https://github.com/SDhilu/Shopping_system.git
cd Shopping_system/volt-store
```

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open the local URL provided by Vite in your browser.
